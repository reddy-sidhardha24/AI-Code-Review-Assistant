3. Add Exception Handling for Network Errors

📖 Problem & Explanation: Wrapping the request in a try/except block and checking `response.ok` ensures graceful failure and clearer error messages.
💡 Recommended Solution: Wrap the request in try/except and check `response.ok` before parsing JSON.

✅ After (Corrected Code): 
try:
    response = requests.get(BASE_URL, params=params)
    response.raise_for_status()
    data = response.json()
except requests.RequestException as e:
    print("Network error:", e)
    exit(1)
🛡️ Reason for Correction: Catches network-related exceptions and prevents uncaught crashes.
